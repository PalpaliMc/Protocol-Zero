# Protocol Zero | پروتکل صفر

یک تجربهٔ فارسی، راست‌چین و واکنش‌گرا برای تمرین معماهای سایبری و کار با ترمینال شبیه‌سازی‌شده. بدون بک‌اند و بدون نیاز به نصب پکیج.

## اجرای محلی

1. فایل ZIP را استخراج کن.
2. `index.html` را در مرورگر باز کن. برای سازگاری بهتر با قابلیت‌های امنیتی مرورگر، اجرای ساده از طریق HTTPS یا یک سرور محلی توصیه می‌شود.
3. برای بررسی سریع روی «ورود آزمایشی» بزن؛ یا از بخش «ساخت حساب» یک حساب محلی بساز.

## انتشار با GitHub Pages

1. یک repository جدید در GitHub بساز.
2. فایل‌های `index.html`، `style.css`، `app.js` و `README.md` را مستقیماً در ریشهٔ repository قرار بده.
3. از **Settings → Pages** بخش **Build and deployment** را روی **Deploy from a branch** بگذار.
4. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و Save کن.
5. پس از پایان انتشار، آدرس Pages در همان بخش نمایش داده می‌شود.

## امکانات

- ثبت‌نام، ورود، نمایش/مخفی‌کردن رمز و ورود آزمایشی
- هش کردن رمز در مرورگر با PBKDF2-SHA256 در محیط‌هایی که Web Crypto پشتیبانی می‌شود
- داشبورد، رتبه‌ها، XP، مأموریت‌ها، تاریخچهٔ فعالیت و نشان‌ها
- ترمینال نمایشی با فرمان‌های `help`، `status`، `whoami`، `missions`، `scan`، `open PZ:001`، `matrix`، `date` و `clear`
- پنج معمای آموزشی، سرنخ‌ها و ذخیرهٔ محلی پیشرفت
- صدای قابل خاموش‌کردن، کاهش حرکت‌ها، پروفایل و طراحی واکنش‌گرا

## نکتهٔ امنیتی مهم

GitHub Pages هاست ایستا است و احراز هویت سمت سرور ارائه نمی‌دهد. حساب‌ها و پیشرفت این پروژه در `localStorage` یا `sessionStorage` همان مرورگر ذخیره می‌شوند؛ بنابراین به دستگاه/مرورگر فعلی محدودند، قابل حذف‌اند و برای اطلاعات حساس یا حساب‌های واقعی امن محسوب نمی‌شوند. هش رمز در مرورگر، این محدودیت را برطرف نمی‌کند. برای کاربران واقعی، ورود امن، بازیابی رمز و امتیازهای ضدتقلب باید یک بک‌اند یا سرویس احراز هویت معتبر اضافه شود. هیچ فرمان ترمینال واقعاً سیستم یا شبکه را اسکن نمی‌کند.
